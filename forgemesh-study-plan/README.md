# ForgeMesh 求职学习计划

这是一份以开源项目 [ForgeMesh](https://github.com/Mekoforge/ForgeMesh) 为主线的求职学习计划。

- **目标岗位**：MaaS / 大模型推理平台开发，Agent 平台作为第二方向。
- **主线**：先吃透 ForgeMesh 已有的核心链路，再在真实 GPU 上拿到自己的数据，然后亲手做 MaaS 接入层和推理感知路由，最后把 Agent 方向以智能诊断 Agent 的形式并进同一个项目。
- **节奏**：每个阶段达到出关标准再往下走；面试准备从阶段 2 开始并行；到“可以开始面试”这个里程碑就开始投递，阶段 3 边面边做。

## 怎么用

- 任务和深挖题都写成了任务列表（`- [ ]`）。做完一项就改成 `- [x]` 并提交，提交历史就是学习记录。
- 没有标“选做”的任务都是必做。时间紧时先砍选做。
- 深挖题勾选的标准是能脱稿讲清“是什么、为什么这么设计、坏了会怎样”。
- 网页版：<https://knightkkop.github.io/Study/>。内容由这些 Markdown 生成，可以直接打勾、按每周投入换算进度。网页上的勾选只保存在当前浏览器，长期记录以 Markdown 为准。源码和发布方法见 [web/](web/)。

## 两点提醒

- **合规**：你现在的工作就是 MaaS，个人开源项目也是 MaaS，最容易被质疑。只用个人设备和个人时间，不使用任何内部代码、文档、数据和算力（包括公司的 GPU），并先确认公司对个人开源项目与对外贡献的规定。简历和面试中，现在公司的工作只讲公开层面的内容。
- **面试时怎么讲 AI 辅助**：ForgeMesh 三轮改进的 174 个提交是 AI 编码 Agent 生成的，面试官看提交历史就能看出来。如实说明，重点讲你怎么保证正确性：每个修复都带在基线上会失败的回归测试，每个分支单独检出都能通过 CI，有 compose 端到端冒烟和 OpenAPI 契约测试。这本身就是 Harness 工程的实践，投 Agent 方向时是加分项；前提是核心链路的代码你都讲得清。
