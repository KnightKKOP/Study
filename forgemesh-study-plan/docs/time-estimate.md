# 时间估算

按学习小时数估算，再按每周投入换算成月份。这是粗估，前提见文末。

## 里程碑

不用全部做完再跳。到“可以开始面试”就可以投目标公司；阶段 3 边面边做，用面试反馈调整重点。

| 里程碑 | 包含 | 累计投入 |
|---|---|---|
| 可以开始面试 | 阶段 0～2，加上简历、刷题和基础知识 | 235～335 小时 |
| MaaS 能力完整 | 再加阶段 3、系统设计和模拟面试 | 330～470 小时 |
| 全部完成 | 再加阶段 4 和阶段 5 | 450～630 小时 |

按每周投入换算成月份（1 个月按 4.33 周算，四舍五入到半个月）：

| 每周投入 | 可以开始面试 | MaaS 能力完整 | 全部完成 |
|---|---|---|---|
| 10 小时 | 5.5～7.5 个月 | 7.5～11 个月 | 10.5～14.5 个月 |
| 12 小时 | 4.5～6.5 个月 | 6.5～9 个月 | 8.5～12 个月 |
| 15 小时 | 3.5～5 个月 | 5～7 个月 | 7～9.5 个月 |
| 20 小时 | 2.5～4 个月 | 4～5.5 个月 | 5～7.5 个月 |

工作日晚上各 1 小时、周末 7～8 小时，大约是每周 12 小时。

## 各阶段的投入

| 阶段 | 预计投入 | 主要花在哪 |
|---|---|---|
| 阶段 0：准备 | 10～15 小时 | 合规确认、提交两个文档 PR、写发布记录、配好本地环境。补丁和脚本都是现成的。 |
| 阶段 1：吃透核心链路 | 70～100 小时 | 文档和 19 个 PR 描述 12～18 小时；核心链路代码约 8 千行，读懂并写笔记 40～55 小时；三个迷你实现 15～25 小时。没写过 Go 再加 20～30 小时。 |
| 阶段 2：推理原理、PyTorch 与 GPU 验证 | 60～90 小时 | 推理原理与四篇论文 25～35 小时；PyTorch 与手写迷你推理 20～30 小时；GPU 验证与压测报告 15～25 小时。 |
| 阶段 3：MaaS 接入层 | 70～100 小时 | 两份 ADR 5～8 小时；OpenAI 兼容接口与模型抽象 30～40 小时；配额 15～20 小时；计量 15～20 小时；冒烟与文档 5～8 小时。 |
| 阶段 4：多副本与推理感知路由 | 70～90 小时 | 多副本与健康检查 30～40 小时；实例指标 8～10 小时；路由插件与三种策略 20～25 小时；对比压测 10～15 小时。 |
| 阶段 5：智能诊断 Agent | 50～70 小时 | MCP server 10～15 小时；诊断 Agent 15～20 小时；故障注入评测集与报告 25～35 小时。 |
| 面试准备线 | 120～165 小时 | 刷题 60～80 小时；基础知识 30～40 小时；系统设计 15～20 小时；简历 5～10 小时；模拟面试 10～15 小时。 |

## 估算的前提

按这样的背景估：Python 熟练，Go 和 PyTorch 有基础，算法题有一段时间没刷；写代码时用 AI 编码工具，但每处改动你都读懂、能解释。

- 没写过 Go：阶段 1 加 20～30 小时。
- 一直在刷题：面试准备减 30～40 小时。
- 不含租 GPU、装环境时的意外折腾。

## 怎么压缩

- 先只做必做项，选做留到拿到 offer 之后。
- 阶段 2 的理论和阶段 3 的编码可以并行。
- 目标公司放到“可以开始面试”之后，之前挑一两家不太想去的练手、校准差距：大厂面试有记录，挂了通常要隔一段时间才能再面。
